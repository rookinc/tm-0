# Receipt 0047

## Title

Character Emerges from Return

## Status

Research receipt.

## Result

TM-0 can derive a state character field from the directed return
structure of the motion graph.

States are grouped into mutual-return classes.

Two states share a class when each is reachable from the other.

Each return class receives one canonical one-hot character.

States in the same class share character.

States in different classes receive different characters.

The derived field covers every registered state.

## Interpretation

Character need not be assigned from outside.

It can emerge from the lawful possibility of mutual return.

A state carries the character of the return class in which the motion
law places it.

## Consequence

The thalion derivation can now begin from:

    motion graph

and derive:

    return classes

    state character field

    connected character-preserving bodies

    internal return

    thalion candidates

This removes the externally authored state-character map from the
current construction.

## Limitation

The derived character identifies strongly connected components.

It is not yet a signed cycle character, switching class, or full
cycle-space functional.

The one-hot coordinate order depends on sorted state names.

A strongly connected graph receives one shared return character.

This is return-class identity, not yet the richer cycle character from
the earlier experiments.

## Keeper

Character is the address of mutual return.
