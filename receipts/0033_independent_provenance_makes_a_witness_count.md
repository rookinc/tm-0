# Receipt 0033

## Title

Independent Provenance Makes a Witness Count

## Status

Research receipt.

## Result

A third report resolves disagreement only when it survives the tested
independence filter.

A receipt is not independent when it repeats:

    the same source occurrence

or:

    the same observation path

A duplicated report does not add another witness.

## Interpretation

Witness multiplicity is not report multiplicity.

A witness earns weight through independently receipted provenance.

The tested triad is therefore:

    three reports

    from three source occurrences

    through three observation paths

## Consequence

The witness layer now distinguishes:

    repeated claim

from:

    independent receipt

Two independent conflicting receipts remain unresolved.

Three independent receipts can break the tie under strict majority.

## Limitation

Independent provenance does not guarantee truth.

It does not rule out:

    coordinated error

    shared hidden causes

    unreliable observation

    false receipts

The strict-majority rule remains supplied.

## Keeper

A repeated claim is not another witness.

Independent provenance makes the witness count.
