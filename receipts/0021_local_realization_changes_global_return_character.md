# Receipt 0021

## Title

Local Realization Changes Global Return Character

## Status

Research receipt.

## Result

Flipping one local relation sign changes the switching-invariant
cycle-space signature while preserving the graph incidence structure.

The relational body remains the same.

Its return character changes.

## Interpretation

The graph incidence structure is the body.

The cycle-space signature is the current return character.

A local realization may alter several global return bits when the
affected relation participates in several independent cycles.

## Consequence

Character is now executable as state over cycles.

The first TM-0 character update is:

    chi_n -> chi_n+1

without:

    adding vertices

    removing vertices

    adding relations

    removing relations

    changing incidence

## Local and Global

The realization is local in the edge-sign assignment.

Its character consequence is distributed across every independent
cycle containing that edge.

## Limitation

possible from a given character state.

energy, or physical motion.

It does not yet feed the updated character back into the possibility
address space.
