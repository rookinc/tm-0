# Receipt 0022

## Title

Possibility Is an Address Space

## Status

Research receipt.

## Result

The current cycle-space character defines a frontier of addressed
candidate realizations.

Each candidate records:

    relation address

    current character

    resulting character

The frontier contains one candidate per relation address in the tested
graph.

## Interpretation

Possibility is not a selected outcome.

Possibility is the address space of lawful candidate realizations
available from the current character state.

The frontier may contain several addresses.

Distinct addresses may lead to the same resulting character.

## Separation

Possibility does not select.

Possibility does not rank.

Possibility does not execute.

It only makes the candidate realizations addressable.

## Consequence

    relational body

    return character

        ->

    possibility address space

        ->

    unresolved candidate realizations

The missing operation is resolution.

Resolution must act on the frontier without becoming the frontier.
