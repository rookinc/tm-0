# Receipt 0018

## Title

Cycle Product Is Complete on One Cycle

## Status

Research receipt.

## Result

For one connected signed cycle, two local sign assignments are
switching-equivalent exactly when they have the same cycle product.

    same cycle product
        <->
    switching-equivalent

## Normal Forms

Every positive cycle is switching-equivalent to:

    all PRESERVE

Every negative cycle is switching-equivalent to:

    exactly one INVERT

## Interpretation

The local sign pattern contains redundant description.

After quotienting by local switching, one connected cycle retains one
invariant bit:

    +1 = SAME return class

    -1 = POLAR return class

## Consequence

The cycle product is not merely preserved by switching.

It completely classifies switching classes on one connected cycle.

The return receipt therefore carries all switching-invariant
orientation information available in the tested one-cycle model.

## Limitation

This result does not yet classify structures with multiple
independent cycles.

A larger incidence structure may require one invariant bit per
independent cycle or some further relation among cycle products.

## Keeper

On one closed cycle, local sign detail reduces to one return bit.
