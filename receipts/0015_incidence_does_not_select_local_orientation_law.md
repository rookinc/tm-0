# Receipt 0015

## Title

Incidence Does Not Select the Local Orientation Law

## Status

Research receipt.

## Result

The same closed incidence structure admits both local laws:

    PRESERVE

    INVERT

For an odd closed chain:

    PRESERVE -> SAME

    INVERT   -> POLAR

For an even closed chain:

    PRESERVE -> SAME

    INVERT   -> SAME

## Interpretation

Direction, incidence, composition, and closure do not determine
whether local traversal preserves or reverses orientation.

Local orientation behaviour is additional structure.

Odd closure does not create inversion.

Odd closure makes the local orientation law globally readable.

## Consequence

Experiment 014 remains conditional:

    if every local traversal inverts orientation,
    then odd closure returns polar

The next question is what minimal local structure distinguishes
PRESERVE from INVERT.

## Keeper

Odd closure is a comparator for local orientation character.

It is not the source of that character.
