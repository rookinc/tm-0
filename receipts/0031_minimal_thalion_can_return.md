# Receipt 0031

## Title

Minimal Thalion Can Return

## Status

Research receipt.

## Result

The smallest tested returning body has two character states.

It supports the closed boundary-preserving path:

    s0 -> s1 -> s0

A one-state system cannot support a non-identity return.

A three-state cycle can return, but is not minimal.

## Interpretation

The minimal thalion candidate and the minimal returning body coincide
in size.

Two states are sufficient for:

    character change

    boundary persistence

    nontrivial return

## Important Distinction

Two states are sufficient for return.

They are not yet sufficient for everything associated with a mature
thalion.

The experiment has not yet derived:

    orientation comparison

    A/B registration

    polarity

    witness

    triadic stabilization

## Consequence

Return does not require three states.

The need for a triad, if it survives, must come from witness or
stabilization rather than from return itself.

## Limitation

The two directed transitions are supplied by the experiment.

The experiment does not derive why departure and return are both
lawful.

It does not yet explain how the return changes or preserves
registration.

## Keeper

Two states are enough to leave and come home.
