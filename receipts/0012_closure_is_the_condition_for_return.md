# Receipt 0012

## Title

Closure Is the Condition for Return

## Status

Research receipt.

## Result

An open composable relation chain does not admit return.

A closed composable relation chain does admit return.

The difference is the final endpoint equivalence:

    final target = first source

## Separation

Closure is a structural condition.

Return admissibility is a possibility created by that condition.

Realized return is a later occurrence that produces a receipt.

Therefore:

    closure is not return

and:

    closure admits return

## Consequence

Return does not need to be introduced as an unrelated primitive law.

Its admissibility follows from closed incidence.

The realization of that admissible return remains distinct from the
closure condition itself.

## Keeper

Closure is the condition that triggers the possibility of return.

Return is what happens when that possibility is realized.
