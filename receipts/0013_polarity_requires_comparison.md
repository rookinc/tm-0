# Receipt 0013

## Title

Polarity Requires Comparison

## Status

Research receipt.

## Result

A completed return receipt does not by itself register polarity.

Without an orientation comparison, its registration is:

    NULL

Comparing equal readings produces:

    SAME

Comparing opposite readings produces:

    POLAR

## Interpretation

Return provides a completed event.

Comparison provides registration.

Opposed orientation provides polarity.

Therefore:

    closure admits return

    return permits comparison

    comparison of opposite readings registers polarity

## Negative Result

The tested mechanics does not force a half-flip merely because return
occurred.

A rule that reverses the returned reading has not yet been derived.

## Consequence

A/B remains downstream of comparison.

The next question is not whether polarity exists.

The next question is what lawful structure makes the returned reading
opposite to the departure reading.

## Keeper

Return comes home.

Comparison tells us how it came home.
