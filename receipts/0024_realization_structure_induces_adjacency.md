# Receipt 0024

## Title

Realization Structure Induces Adjacency

## Status

Research receipt.

## Result

Two character states are minimally adjacent when exactly one
cycle-space bit differs.

    zero differing bits
        same character state

    one differing bit
        minimally adjacent

    more than one differing bit
        not minimally adjacent

## Interpretation

Adjacency does not need to be supplied as an external topology in the
tested model.

It can be derived from the smallest admitted character change.

The realization structure of possibility induces its neighbourhood
relation.

## Consequence

The current boundary construction becomes:

    character
        -> classification

    minimal transformability
        -> adjacency

    cross-class adjacency
        -> boundary

This removes externally supplied adjacency from the earlier model.

## Limitation

The experiment assumes that one cycle-space bit is the correct unit of
minimal character change.

It has not yet proved that every one-bit change is produced by exactly
one local edge-sign realization.

It does not derive resolution, selection, time, geometry, energy, or
physical motion.

## Keeper

The way character may change determines which possibilities are
neighbours.
