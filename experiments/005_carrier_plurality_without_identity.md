# Experiment 005

## Title

Carrier Plurality Without Identity

## Status

Executable negative result candidate.

## Question

Can TM-0 distinguish two carriers carrying the same null registration
without assuming names, identifiers, coordinates, histories,
relations, or implementation object identity?

## Current Carrier Description

A carrier is currently described only by:

    internal register value

For the test case, both carriers occupy:

    NULL

## Procedure

1. Instantiate one anonymous null carrier.
2. Instantiate a second anonymous null carrier.
3. Compare them using only admitted structural content.
4. Place both in an extensional catalogue.
5. Refuse to treat Python object identity as TM-0 structure.

## Result Sought

If both carriers collapse to one visible description, then plurality
is not derivable from register value alone.

## Important Distinction

Python may allocate two different runtime objects.

That implementation fact is not automatically an ontological
distinction in TM-0.

The experiment therefore distinguishes:

    runtime object identity

from:

    admitted mechanical distinction

## Boundary

This experiment does not prove that multiple carriers cannot exist.

It tests only whether plurality is visible in the current language.

A future distinction may require relation, occurrence, history,
boundary structure, or another earned primitive.
