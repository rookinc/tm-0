# Experiment 013

## Title

Return Does Not Force Polarity

## Status

Executable negative result candidate.

## Question

Does a realized return automatically create A/B polarity, or is an
additional orientation comparison required?

## Starting Result

Experiment 012 established:

    closure admits return

    realized return produces a receipt

The receipt confirms that traversal returned to its departure
junction.

It does not yet contain an outbound/returned orientation comparison.

## Construction

A completed return may be read as:

    FORWARD

or:

    REVERSED

The experiment compares two readings of the same return receipt.

Comparison outcomes are:

    NULL

        No comparison has occurred.

    SAME

        Both readings have the same orientation.

    POLAR

        The readings have opposite orientation.

## Expected Result

A return receipt alone should remain NULL with respect to orientation
registration.

Polarity should appear only when:

    FORWARD is compared with REVERSED

or:

    REVERSED is compared with FORWARD

## Interpretation

Closure does not itself create polarity.

Return does not itself create polarity.

Return supplies a completed event that may be read and compared.

The half-flip is therefore not yet derived from return alone.

It remains a candidate rule or structure that produces opposite
readings of one completed return.

## Boundary

This experiment does not derive why a returned reading should reverse.

It does not derive A and B as named intrinsic values.

It does not establish physical orientation, geometry, motion, agency,
memory, witness, or character accumulation.

It tests only whether polarity is forced by the existing return
receipt.
