# Experiment 038

## Title

Context Is Derived from a Realized Event

## Status

Executable candidate.

## Question

Can witness context be reconstructed from a realized event rather than
from prepared boundary and character inputs?

## Starting Result

Experiment 037 derived witness context from:

    normalized boundary signature

    ordered character

Those structures were still supplied directly.

## Construction

A realized event records:

    source state

    target state

    traversed relation

    boundary contacts

    cycle residue

The event is validated before use.

Its boundary signature is derived from:

    realized transition

    traversed relation

    boundary contacts

Its character is derived from:

    whether the state changed

    whether a boundary was contacted

    ordered cycle residue

The derived structures are then passed into the structural context
constructor.

## Result

The boundary signature is reconstructed from the realized event.

The character is reconstructed from event behavior and cycle residue.

Equivalent boundary-contact order gives the same normalized context.

Changing the traversed relation changes the context.

Changing the cycle residue changes the context.

Malformed event records are rejected.

## Interpretation

Context can be a consequence of execution.

It need not be supplied as a descriptive label or as a prepared
structural address.

A realized event can carry enough trace to reconstruct the context in
which witness reliability should be evaluated.

## Consequence

The emerging witness sequence is now:

    realized event

    derived boundary signature

    derived event character

    structural context address

    context-specific closure history

    earned reliability

    weighted arbitration

## Boundary

The event record itself is still supplied.

The source and target states, relation name, boundary contacts, and
cycle residue are not yet generated by an executable transition
system.

The event character uses a bounded toy encoding.

Boundary contact is mandatory in the current scaffold, so the
crossed-boundary bit is always one for valid events.

The experiment does not yet derive cycle residue from a traversed
closed walk.

## Keeper

A realized event carries the address of the context it created.
