# Experiment 007

## Title

Continuity Without Assigned Identity

## Status

Executable candidate.

## Question

Can a carrier remain referable across later realizations through
continuity alone, without assigning a name, identifier, coordinate,
timestamp, or implementation identity?

## Starting Result

Experiment 006 showed that occurrence history can preserve
multiplicity without preserving enduring individuation.

## Construction

A continuity trace is an ordered sequence of internal states.

Example:

    NULL
    NULL -> CHARACTERIZED
    NULL -> CHARACTERIZED -> NULL

A later trace continues an earlier trace when the earlier trace is an
exact prefix of the later trace.

## Candidate Law

Continuity is preserved by lawful extension:

    earlier states + one non-identity realization

No external identity token is added.

## Expected Result

The model should recognize:

    NULL

as the beginning of:

    NULL -> CHARACTERIZED

and recognize both as prefixes of:

    NULL -> CHARACTERIZED -> NULL

## Expected Limitation

Two independently constructed but identical histories remain
extensionally equal.

Therefore continuity may preserve lineage while still failing to
preserve plurality among identical lineages.

## Boundary

This experiment does not derive time.

Order is represented only as sequence position inside a trace.

It does not establish persistent identity between two extensionally
identical histories.

It does not derive relation, character, polarity, witness, geometry,
or a thalion society.
