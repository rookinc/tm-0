# Experiment 012

## Title

Closure Admits Return

## Status

Executable candidate.

## Question

Is return already contained in closure as an admissible continuation,
or must return be added as an unrelated law?

## Starting Result

Experiment 011 represented closure as a composable relation sequence
whose final target port is equivalent to its first source port.

Closure was detectable, but no return operation had yet been modeled.

## Separation

Experiment 012 distinguishes three layers.

### Closure

A structural incidence condition:

    final target junction = first source junction

### Return Admissibility

The closed structure permits a traversal to end at its departure
junction.

### Realized Return

The admissible traversal is completed and produces a receipt.

## Open Chain

An open composable chain does not admit return.

Attempting to realize return raises an error.

## Closed Chain

A closed composable chain admits return.

A return receipt records:

    relation traversal order

    departure port

    return port

The return port and departure port occupy the same endpoint
equivalence class.

## Expected Result

Closure should be necessary and sufficient for return admissibility in
the tested model.

Closure alone should not automatically create a return receipt.

## Interpretation

Closure is not return.

Closure establishes the lawful possibility of return.

Realized return is a distinct occurrence made possible by closure.

## Boundary

This experiment does not explain what selects or initiates a return.

It does not assume agency, permission, automatic execution, physical
motion, time, character, memory, witness, or geometry.

It tests only the relation between closure and return admissibility.
