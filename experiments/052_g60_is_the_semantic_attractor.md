# Experiment 052: G60 Is the Semantic Attractor

## Question

Has TM-0 accumulated enough executable ontology to stop generating its
own semantic agenda and return to G60 as the source of further required
distinctions?

## Background

Experiments 039 through 051 established executable distinctions among:

    rule
    event
    step
    path
    trace
    receipt
    boundary
    body
    thalion
    context
    witness
    reliability
    arbitration
    intrinsic character

These distinctions were earned through executable tests.

Recent discussion attempted to extend TM-0 with concepts including:

    judgment
    precedent
    retention
    contextual quotient

Those concepts may eventually be required.

They have not yet been earned by a bounded G60 phenomenon.

## Candidate Research Rule

Further permanent TM-0 ontology shall be admitted only when a specific
G60 phenomenon exposes a distinction that the current executable
language cannot express.

The required sequence is:

    G60 phenomenon
    ->
    bounded mathematical description
    ->
    demonstrated TM-0 expressive gap
    ->
    smallest graph-independent candidate
    ->
    executable admission test

Usefulness alone is not sufficient for admission.

Analogy alone is not sufficient for admission.

A concept shall not be admitted merely because it improves prose,
architecture, or institutional interpretation.

## Current G60 Frontiers

The current candidate frontiers are:

1. the three lawful quotient systems
2. the signed cocycle
3. the source and body distinction
4. projection without body mutation

Only one frontier shall be examined at a time.

The frontiers shall not be merged before their independent semantic
requirements are known.

## Executable Test

This experiment does not yet add a new runtime object.

It establishes a test for future admission:

1. identify one bounded G60 phenomenon
2. express it using the current TM-0 ontology
3. exhibit the exact distinction that cannot be expressed
4. propose the smallest graph-independent candidate
5. reject the candidate if an existing object already suffices
6. admit the candidate only after a focused executable test passes

## Result Classification

This experiment is a research-boundary scaffold.

It is not an executable semantic result.

It does not prove that G60 is unique.

It does not prove that every TM-0 object must arise from G60.

It constrains the next phase of this project.

## Interpretation

TM-0 has bootstrapped a usable executable language.

G60 may now serve as a justified semantic attractor rather than merely
a historical inspiration.

The next question is no longer:

    What should TM-0 contain?

The next question is:

    What does G60 require TM-0 to say?

## Boundary

No new permanent semantic object is admitted here.

Judgment is not admitted.

Precedent is not admitted.

Retention is not admitted.

Contextual quotient is not admitted.

The three G60 quotient systems remain mathematical targets, not yet
generalized TM-0 objects.

The current TM-0 ontology remains open to revision if a G60 phenomenon
demonstrates that an existing distinction is incorrect or insufficient.

## Keeper

Never invent because useful.

Only admit because necessary.
