# Experiment 023

## Title

Boundary Requires Adjacency

## Status

Executable candidate.

## Question

Is a character-induced partition of possibility already a boundary,
or does boundary require adjacency between addresses?

## Starting Result

Experiment 022 made possibility executable as an address space of
candidate realizations.

The current question is whether character can partition that space
into:

    ADMISSIBLE

    STRUCTURED_ABSENCE

and whether that partition alone is enough to define a boundary.

## Construction

A classifier assigns every possibility address to exactly one class:

    ADMISSIBLE

    STRUCTURED_ABSENCE

This creates a partition.

A separate adjacency relation specifies which addresses meet.

Boundary addresses are those participating in adjacency across the
partition:

    ADMISSIBLE <-> STRUCTURED_ABSENCE

## Result

The partition exists without any adjacency.

Without adjacency, the boundary set is empty.

Adjacency within one class does not create a boundary.

Cross-class adjacency creates a boundary at the two meeting addresses.

The same partition can produce different boundary sets under different
adjacency relations.

## Interpretation

A bare partition creates distinction.

It does not yet create a boundary set.

Boundary requires both:

    classification

    adjacency

Structured absence is one side of the partition.

Boundary is where structured absence meets admissibility.

## Consequence

The current ladder is:

    character
        -> partition of possibility

    partition
        -> admissible and structured absence

    adjacency
        -> meeting relation

    cross-class adjacency
        -> boundary

## Boundary

This experiment assumes adjacency.

It does not derive adjacency from the possibility address space.

It does not yet model boundary persistence, body formation, resolution,
selection, probability, time, geometry, or physical motion.

## Keeper

Distinction makes two sides.

Adjacency makes their boundary visible.
