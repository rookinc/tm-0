# Experiment 031

## Title

Minimal Returning Body

## Status

Executable candidate.

## Question

Can the minimal two-state thalion candidate support a nontrivial closed
return while preserving one boundary?

## Starting Result

Experiment 030 identified the smallest tested thalion candidate as:

    two character states

    one persistent boundary

    one boundary-preserving transition

That established nontrivial internal change.

It did not establish return.

## Construction

A returning body requires a positive-length closed transition path that
remains inside one boundary class.

The experiment compares:

    one state

    two states

    three states

## Result

A one-state system has no non-identity return.

A two-state system supports:

    s0 -> s1 -> s0

when both transitions preserve the same boundary.

A boundary-changing path does not count as return inside the same body.

A three-state cycle also supports return, but is not minimal.

The smallest tested returning body has two states.

## Interpretation

The minimal thalion candidate and the minimal returning body coincide
in size.

Two states are sufficient for:

    nontrivial character change

    boundary persistence

    closed return

The return requires two directed transition occurrences:

    departure

    return

## Consequence

A two-state thalion candidate can already carry a complete internal
return cycle.

More than two states are not required for return itself.

Additional structure may still be required for:

    polarity

    comparison

    registration

    witness

    triadic stabilization

## Boundary

The transition system is supplied by the experiment.

The experiment does not derive why both directions are lawful.

It does not derive orientation, A/B registration, witness, or stable
society.

## Keeper

The smallest body that can change character can also come home.
