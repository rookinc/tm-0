# Experiment 024

## Title

Adjacency From Minimal Transformability

## Status

Executable candidate.

## Question

Can adjacency between possibility addresses be derived from the
smallest character change rather than supplied as an external
topology?

## Starting Result

Experiment 023 showed that a boundary requires:

    partition

    adjacency

    cross-class contact

Adjacency remained assumed.

## Construction

Character is represented by a cycle-space sign signature.

Two character states are defined as adjacent when exactly one
cycle-space bit differs.

    zero differing bits
        same state

    one differing bit
        minimally transformable

    more than one differing bit
        not minimally adjacent

## Result

Identical character states are not adjacent.

States differing in exactly one cycle-space bit are adjacent.

States differing in two bits are not minimally adjacent.

Character states must use the same cycle-space addresses before they
can be compared.

## Interpretation

Adjacency can be derived from one-step transformability in character
space.

No separate geometric or topological neighbourhood is required in the
tested model.

The possibility address space acquires adjacency from the realization
law itself.

## Consequence

Boundary can now be constructed from:

    character-induced classification

    adjacency derived from minimal transformability

    cross-class contact

This removes one imported structure from Experiment 023.

## Boundary

This experiment assumes that one cycle-bit change is the minimal
realization.

It does not yet prove that every one-bit character change is reachable
through one local edge-sign realization.

It does not derive resolution, selection, time, geometry, energy, or
physical motion.

## Keeper

Possibilities are adjacent when one minimal realization separates
them.
