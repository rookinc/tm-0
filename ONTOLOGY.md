# TM-0 Executable Ontology

## Purpose

This document records the current executable ontology earned by TM-0
experiments.

It is distinct from `VOCABULARY.md`.

`VOCABULARY.md` records the ordered primitive terms from which TM-0 is
constructed.

`ONTOLOGY.md` records the executable objects and distinctions currently
derived from those primitives.

This document freezes the current ontology at the boundary established
by Experiment 052.

It does not claim that the ontology is complete or final.

## Primitive Execution Surface

### Registered State

A state admitted to an executable transition system.

### Lawful Relation

A registered directed relation between states.

A lawful relation permits execution.

It is not an executed event.

### Execution

The realization of a lawful transition.

Execution selects one lawful possibility and produces historical fact.

### Step Event

The realized record of one executed transition.

A step event records local execution.

It does not contain path-earned residue.

## Historical Surface

### Step Trace

The local trace emitted by one realized step.

### Path

An ordered sequence of executed steps.

A path is not merely a set of visited states.

### Path Receipt

A record derived from accumulated path history.

A path receipt may record:

    visited-state history
    return detection
    traversal residue

A path receipt is not a step trace.

### Return

The arrival of an executed path at a previously visited state under the
applicable return condition.

Return is earned by execution history.

It is not implied by the existence of a graph cycle alone.

## Boundary Surface

### Region

A selected connected subset of the motion graph.

### Boundary

A structural object derived from a connected region and its internal,
incoming, and outgoing relations.

A boundary is not merely a supplied label.

### Boundary Contact

A runtime event derived when execution crosses a registered boundary
cut.

Boundary structure and boundary contact are distinct.

## Character Surface

### State Character

A graph-derived field associated with registered states.

Current character constructions include:

    mutual-return class
    directed-cycle participation
    deterministic fundamental-cycle participation
    cycle-rank loss under state deletion
    refined state-deletion damage profile

### Intrinsic Character

A character derived from the motion graph rather than supplied as an
external state label.

Current intrinsic character remains perturbation-derived.

It is not a complete graph invariant.

### Damage Profile

The state-deletion signature containing:

    cycle-rank loss
    undirected component gain
    surviving directed return-class count
    largest surviving return-class size

The damage profile records selected structural summaries.

It is not the full surviving graph.

## Body Surface

### Body Candidate

A connected character-preserving region with a nonempty graph cut.

A body candidate is structurally derived.

It does not become a thalion merely by existing.

### Thalion Candidate

A nontrivial body candidate containing an internal directed return.

In the current scaffold, a thalion candidate contains at least two
states.

A thalion candidate is an executable structural candidate.

It is not yet a claim about physical matter, life, agency, or
consciousness.

## Witness Surface

### Structural Context

The relevant structural conditions under which an event is evaluated.

Context is not identical to global history.

### Witness History

Accumulated context-specific closure evidence associated with realized
events.

### Earned Reliability

Reliability derived from applicable witness history.

Report count alone does not earn reliability.

Global reliability does not imply contextual reliability.

### Arbitration

The comparison of competing reports using applicable earned
reliability.

Arbitration consumes evidence.

It does not create historical execution.

## Locked Distinctions

    rule is not event

    step is not cycle

    step trace is not path receipt

    graph cycle is not executed return

    motion is not boundary meaning

    boundary is not boundary contact

    supplied label is not intrinsic character

    body is not thalion

    report count is not earned reliability

    global reliability is not contextual reliability

## Deferred Candidates

The following concepts are not admitted:

    judgment
    precedent
    retention
    contextual quotient

They may be reconsidered only if a bounded G60 phenomenon demonstrates
that the current ontology cannot express a required distinction.

## G60 Admission Boundary

A permanent extension must pass through:

    G60 phenomenon
    ->
    bounded mathematical description
    ->
    demonstrated expressive gap
    ->
    smallest graph-independent candidate
    ->
    focused executable admission test

Usefulness alone is insufficient.

Analogy alone is insufficient.

Architectural convenience alone is insufficient.

## Research Boundary

The present ontology does not derive G60.

The present ontology does not explain the three quotient systems.

The present ontology does not yet give a semantic account of the signed
cocycle.

The relation among source, body, and witness remains open.

Projection without body mutation remains an open semantic frontier.
