# TM-0

TM-0 is the smallest executable hypothesis of Thalean Mechanics.

It is not a graph engine.

It is not a physics engine.

It is not a simulation of G15, G60, or G900.

Its purpose is to determine whether stable relational character can emerge from repeated lawful cycles of possibility, relation, closure, return, and registration.

Nothing is assumed except that possibility may become relation.

Everything else must earn its existence.

## Core Question

Can recursive character emerge without assuming geometry, coordinates, graphs, identity, agency, probability, or physics?

If yes, larger Thalean structures should eventually emerge naturally.

If no, the hypothesis fails.

## Standing Rules

1. Nothing has coordinates.

2. Nothing moves.

3. Nothing possesses identity initially.

4. Graphs are forbidden until they emerge.

5. Every line of code must correspond to exactly one primitive concept.

6. Do not protect the idea.
   Make the idea protect itself.
